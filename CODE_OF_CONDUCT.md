# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and assume good intent.
- Criticize the work, never the person.
- No harassment, insults, discrimination or exposure of private data.

## Reporting

Use the private form in the Security tab of this repository, under "Report a vulnerability", and start the title with
"Conduct". Reports stay private. The maintainer may edit or remove contributions and block whoever breaks these rules.
